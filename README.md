# Library-Management-System-Java
Mini Library Management System using OOP concepts in java

## 📌 Objective
Develop a mini system to manage books and users using Object-Oriented Programming concepts.

## 🛠 Tools Used
- Java
- VS Code
- Terminal

## 📂 Project Structure
- Book.java
- User.java
- Library.java
- Main.java

## 🚀 Features
- Add Books
- Display Books
- Issue Book
- Return Book

## 🧠 OOP Concepts Used
- Encapsulation
- Abstraction
- HAS-A Relationship
- Constructors
- Method Implementation

## ▶️ How to Run
1. Compile:
   javac *.java
2. Run:
   java Main
